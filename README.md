# ad-l4 | AD-07-1 The blog Site

Sitio web de un blog de libros, "Páginas y Letras", creado con HTML y CSS como parte de la simulación de proyecto SCRUM del bootcamp Full Stack Java de Generation México.

## 📄 Páginas

- **Inicio:** presentación del blog y reseñas de libros
- **Quiénes somos:** información sobre la autora del blog
- **Contacto:** página de contacto

## 📚 Libros reseñados

- *1984*, de George Orwell
- *Azteca*, de Gary Jennings
- *El hombre en busca de sentido*, de Viktor Frankl

## 🛠️ Tecnologías

HTML5 · CSS3 (modelo de caja, navegación fija) · Git/GitHub

## ✅ Tareas del laboratorio

1. Repositorio en GitHub
2. Backlog
3. Barra de navegación
4. Pie de página
5. Página de inicio
6. Página "Quiénes somos"
7. Página de contacto
